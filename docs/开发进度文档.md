## 关键设计决策

### 操作系统栈类比（2026-07-11）
论文写作和代码项目是同构问题——AI 读论文 = AI 读陌生项目。不需要研究"AI 怎么读论文高效"，认出结构同构性，把答案借过来。

```
tex 文件组     →  字节（结构编码在 TeX 语法里）
latex_parser   →  操作系统（字节 → Section 树）
doc_graph      →  终端命令（ls/cd/grep — 查询接口）
context_svc    →  man 命令（拼信息，不做判断）
argument.md    →  README（先看这个）
```

### 三职责分离（2026-07-10）
AI 不替用户做决定，只回答"你要的东西在这里"。决策权在调用方。

### 上下文引擎不是拼装器（2026-07-10）
从"算出最优上下文一次性喂给 AI"改为"提供可组合查询接口，AI 自己决定查什么"。策略放 prompt，不放代码。

### 模块接口标准化 — 文件系统契约（2026-07-13）
放弃函数传参，改用 `tasks/{project}/{B|C|D|E}/request.json`（新覆旧）。各组 `run(paper_dir)` 统一签名，读自己组的 JSON。测试零成本，不依赖前端时序。

### autolib/ 只读（2026-07-13）
各组只改自己模块文件，不动 `autolib/`、`server/`、`frontend/`。需要新功能找同学 A。

## 端到端通路

```
前端请求弹框 → POST API → 写 tasks/{proj}/{组}/request.json → 调模块 run(paper_dir)
    → 模块读 request.json → 调用 LLM → 返回结果 → 前端展示 diff / 应用修改
```

写入自动 commit（git），编译 xelatex 自动处理交叉引用。
