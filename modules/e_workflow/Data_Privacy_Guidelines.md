# AutoResearch 数据隐私保护协议

> 版本 v1.0 | 最后更新 2026-07-20
> 本协议说明 AutoResearch 如何处理您的论文数据，以及您为保护学术隐私应采取的措施。

---

## 一、总则

AutoResearch 在本地环境（Claude Code）中运行，处理您的学术论文。我们理解学术写作的特殊性——未发表的手稿、双盲审稿要求、以及研究数据的敏感性。

**核心承诺：您的论文数据默认不离开您的本地环境。当使用云端 AI 服务时，您有权了解数据传输的范围和风险。**

---

## 二、数据存储位置

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 论文 .tex 源文件 | 本地 `tasks/` 目录 | 由您完全控制 |
| 参考文献 .bib 文件 | 本地 `tasks/` 目录 | 可能包含未发表文献 |
| 编译产物 PDF | 本地 `tasks/<project>/build/` | 不自动上传 |
| Git 版本历史 | 本地 `.git/` 目录 | 每次修改自动 commit |
| 论文 PDF 缓存 | 本地 `cache/` 目录 | arXiv 下载的论文缓存 |
| 公式识别图片 | 经 SimpleTex API 传输 | 仅当使用公式识别功能时 |

---

## 三、AI 服务数据传输

AutoResearch 通过 nature-skill（Claude Code Skill）调用 AI 服务。数据传输取决于您配置的 AI 提供商：

### 3.1 文本处理（润色、检查、写作）

| 场景 | 传输内容 | 接收方 |
|------|---------|--------|
| 段落润色 | 选中的段落文本 + 上下文摘要 | 您配置的 AI 提供商 |
| 全文处理 | 论文结构骨架 + 分段文本 | 您配置的 AI 提供商 |
| 引用检索 | claim 文本片段（非全文） | Semantic Scholar / PubMed 等学术 API |

### 3.2 您应了解的风险

| 风险 | 说明 | 缓解措施 |
|------|------|---------|
| AI 提供商数据留存 | 部分提供商可能留存 API 调用数据用于训练 | 选择承诺不用于训练的提供商（如通过 API 调用的 OpenAI/Anthropic） |
| 传输中截获 | 网络传输可能被第三方截获 | 所有 API 调用使用 HTTPS 加密 |
| 未发表论文泄露 | 云端处理意味着论文内容离开本地 | 对敏感论文，仅在本地处理，不使用云端 API |

### 3.3 建议的安全措施

1. **优先使用本地模型**：如条件允许，使用本地部署的开源 LLM
2. **关闭对话历史**：确保 AI 提供商不保存您的 API 调用日志
3. **分段处理**：不要一次性上传完整论文，逐段处理
4. **去除敏感信息**：处理前删除作者名、机构、基金号

## 四、盲审合规

提交双盲审稿的期刊（如 Nature、Science、IEEE/ACM 大部分期刊）要求手稿不包含作者身份信息。

### 4.1 G6 自动检测项

AutoResearch 的 G6 Gate 自动检测以下身份泄露风险：

- 邮箱地址（`author@university.edu`）
- 机构名称（"University of ...""... 大学"）
- ORCID 标识符
- 基金编号

### 4.2 人工检查清单

以下项目 G6 无法自动检测，需您自行确认：

- [ ] 正文中的自我引用未使用第一人称（避免 "In our previous work [1]" → 改为 "In previous work [1]"）
- [ ] 致谢部分已在盲审版本中移除
- [ ] 代码/数据仓库链接使用匿名版本（如 Anonymous GitHub 而非实际用户名）
- [ ] PDF 元数据中无作者信息（LaTeX 默认会嵌入 `\author{}` 到 PDF meta）
- [ ] 图表中无水印或机构 Logo
- [ ] Supplementary Material 同样经过匿名化

### 4.3 投稿前恢复

盲审版本通过后，使用 Git 回退或保留原始文件，在投稿最终版中恢复作者信息。

## 五、第三方服务数据处理

| 服务 | 用途 | 数据传输 | 隐私政策 |
|------|------|---------|---------|
| SimpleTex | 公式图片 → LaTeX 转换 | 上传公式图片 | https://simpletex.cn |
| Semantic Scholar | 文献检索 | 发送检索关键词 | https://api.semanticscholar.org |
| arXiv | 论文下载 | 请求论文元数据 | https://info.arxiv.org |
| PubMed | 文献检索 | 发送检索关键词 | https://pubmed.ncbi.nlm.nih.gov |
| Crossref | 引用验证 | 发送 DOI/标题 | https://crossref.org |

## 六、用户数据权利

您拥有以下权利：

1. **数据所有权**：`tasks/` 目录下的所有文件属于您，不包含任何隐藏的数据采集
2. **完全删除**：删除 `tasks/<project>/` 目录即可清除该论文的所有本地数据
3. **Git 历史控制**：您可以通过 `git log`/`git revert` 完全控制版本历史
4. **离线使用**：除 API 调用外，所有功能均可离线运行

---

## 七、安全事故报告

如果您发现以下情况，请立即停止使用并联系我们：

- 论文内容意外出现在 AI 提供商的训练数据中
- API Key 泄露或异常使用
- 未发表的论文被第三方获取

---

点击"同意"即表示您确认：
